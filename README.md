# Factorial of a Number

## Description

This Python program calculates the factorial of a non-negative integer using a `for` loop.

The factorial of a number `n` is the product of all positive integers from 1 to `n`.

For example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

Also:

```text
0! = 1
```
